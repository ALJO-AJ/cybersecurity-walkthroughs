# OverTheWire: Bandit

## About

This repository documents my practical learning journey through the OverTheWire Bandit wargame.

The objective is to develop Linux command-line skills and understand fundamental cybersecurity concepts through hands-on challenges.

## Topics Covered

- Linux fundamentals
- SSH connections
- File and directory management
- Linux permissions
- File searching
- Text processing
- Networking basics
- Encoding and decoding
